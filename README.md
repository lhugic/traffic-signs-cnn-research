# Исследование архитектуры CNN: распознавание дорожных знаков

## О проекте
Академическая курсовая работа по глубокому разбору алгоритмов компьютерного зрения.

**Важно:** программная реализация основана на открытом решении с Kaggle. Главная ценность проекта — подробная декомпозиция модели и математический анализ нейронных сетей, а не написание кода с нуля.

## Что разобрано в работе
- Математическая модель CNN: принципы работы свёрточных слоёв и пулинга
- Оптимизация: функция потерь и математика оптимизатора Adam
- Метрики качества модели
- Проблема переобучения и методы аугментации данных
